# kicklog-site

Static site for KickLog (踢迹), served with GitHub Pages from `main` / root.

- `/` — landing page
- `/privacy/` — Privacy Policy (English, default)
- `/privacy/zh/` — 隐私条款（中文）
- `/privacy/en/` — redirect to `/privacy/` (keeps old links working)
- `/terms/` — Terms of Use (English, default)
- `/terms/zh/` — 使用条款（中文）
- `/support/` — Support (English, default; App Store Connect Support URL)
- `/support/zh/` — 技术支持（中文）
- `/app/` — App landing page (English / 中文 toggle; `/app/zh/` redirects to `/app/?lang=zh`)

Plain HTML, no build step, no external assets or trackers. Contact: kicklogsupport@gmail.com
